# Código de conducta

Queremos una colaboración respetuosa y centrada en la evidencia. Trata a las demás personas con consideración, acepta correcciones de buena fe y evita insultos, acoso, amenazas o difusión de datos privados. Los desacuerdos técnicos se resuelven con argumentos y pruebas, sin atribuir intenciones personales.

Quienes colaboren deben respetar estas pautas en las conversaciones y contribuciones relacionadas con el proyecto. Las conductas incompatibles podrán recibir moderación proporcional, incluida la retirada de contenido o la restricción de participación, por quien administre el espacio correspondiente.

Aún no existe un contacto privado de moderación designado; no se debe comunicar información personal o sensible mediante una incidencia pública. Hasta que el propietario confirme un canal, solicita uno apropiado sin revelar esos detalles en público. Este texto no adopta ni atribuye una política de terceros.
