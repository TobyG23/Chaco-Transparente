# Cabeceras de seguridad — propuesta para una futura previsualización

Estado: diseño local, no aplicado. La exportación de Next.js (`output: "export"`, `trailingSlash: true`) no configura las cabeceras del servidor. Sólo el proveedor seleccionado podrá aplicarlas y deberá cubrir `/`, las cinco rutas restantes, 404 y los archivos de `/_next/static/`. `noindex` no es un control de acceso.

## Política inicial, para validar en un entorno HTTPS autorizado

| Cabecera | Valor inicial propuesto | Condición y efecto |
| --- | --- | --- |
| `Content-Security-Policy-Report-Only` | `default-src 'self'; base-uri 'none'; object-src 'none'; frame-ancestors 'none'; form-action 'self'; script-src 'self' <hashes-de-cada-script-inline>; style-src-elem 'self' <hashes-de-estilos-inline>; style-src-attr 'unsafe-inline'; img-src 'self' data:; font-src 'self'; connect-src 'self'; media-src 'none'; frame-src 'none'; worker-src 'none'; manifest-src 'self'; upgrade-insecure-requests` | Primero observar violaciones sin romper la hidratación. Sustituir los marcadores por hashes SHA-256 calculados del **artefacto exacto** que se vaya a publicar, no copiar hashes de una compilación anterior. No configurar `report-uri`/`report-to` sin un receptor y tratamiento de privacidad aprobados. |
| `X-Content-Type-Options` | `nosniff` | Exige MIME correcto para JS y CSS; comprobarlo en el host. |
| `Referrer-Policy` | `strict-origin-when-cross-origin` | El portal oficial y GitHub pueden recibir el origen del sitio al seguir enlaces. Elegir `no-referrer` si el propietario prefiere no transmitirlo. |
| `Permissions-Policy` | `camera=(), microphone=(), geolocation=(), payment=(), usb=()` | El portal no utiliza estas capacidades. Comprobar sintaxis y soporte del proveedor/navegadores. |
| `X-Frame-Options` | `DENY` | Complementa `frame-ancestors 'none'` en clientes antiguos. Impide incrustar la previsualización. |
| `Strict-Transport-Security` | `max-age=31536000` | **No aplicar todavía**: primero verificar dominio, certificado y redirección HTTPS. Añadir `includeSubDomains` sólo tras inventariar subdominios; no pedir `preload` de entrada. |

El HTML estático actual incluye scripts inline de Next/React distintos por ruta y estilos inline en los HTML de error. Un nonce fijo incorporado al HTML estático no proporciona la protección de un nonce por solicitud. Para una CSP efectiva: inventariar **todos** los HTML (`index.html`, cada ruta, `404.html`, `404/index.html`, `_not-found/index.html`), calcular SHA-256 del contenido UTF-8 exacto de cada bloque inline y generar una política común con la unión de hashes o políticas específicas por ruta. Construir y promover HTML y cabeceras como una sola versión inmutable. `script-src 'self'` sigue siendo necesario para los chunks externos; evitar `'unsafe-inline'` en scripts. La excepción de `style-src-attr 'unsafe-inline'` se limita a atributos de estilo del 404 y se revisará tras ensayar alternativas basadas en hashes. Pasar de Report-Only a `Content-Security-Policy` exigible sólo cuando todas las rutas, navegación hidratada, 404 y activos hayan superado prueba sin violaciones inesperadas.

Los enlaces de salida al conjunto oficial y al repositorio no son cargas de recursos: no requieren ampliar `connect-src` ni `script-src`. No se han autorizado analítica, API, fuentes, imágenes ni scripts remotos. Si se agregan, revisar las directivas específicamente, nunca abrir comodines por anticipado. `Cross-Origin-Opener-Policy: same-origin` y `Cross-Origin-Resource-Policy: same-origin` quedan para ensayo de compatibilidad; no imponer COEP sin evaluar integraciones.

## Compatibilidad con el export observado (Misión 005.1)

El inventario de los **nueve HTML del export existente** halló tres scripts inline por HTML; los tres HTML de error (`404.html`, `404/index.html`, `_not-found/index.html`) contienen además un bloque `<style>` y cuatro atributos `style` cada uno. El árbol observado comprende también 28 TXT, 11 JS y un CSS; el inventario de hashes debe reproducirse sobre un **build fresco** antes de cualquier promoción. No insertar aquí hashes de un build antiguo ni afirmar que estas cuentas garantizan la siguiente compilación. El HTML de error no tiene garantizado un HTTP 404 sólo por contener un título 404.

Para Pages Direct Upload, un futuro `_headers` debe viajar **dentro del artefacto aprobado**, no ser copiado manualmente desde un documento; ese archivo de configuración debe ser autorizado como excepción explícita del inventario y probado en el host. La línea CSP puede exceder los [2.000 caracteres por línea de `_headers`](https://developers.cloudflare.com/pages/configuration/headers/) si se unen todos los hashes de las nueve rutas: medir bytes de la línea generada y usar reglas por ruta si hace falta, sin fragmentar una cabecera a ciegas. También [Workers Static Assets](https://developers.cloudflare.com/workers/static-assets/headers/) aplica `_headers` sólo a respuestas de activos, no a respuestas del código Worker. En ambos casos verificar prioridad/rutas y respuestas de error efectivas.

La excepción `style-src-attr 'unsafe-inline'` es provisional: en CSP3 `style-src-attr` controla atributos, mientras `style-src-elem` controla `<style>`; comparar alternativas de mover estilos a CSS local o hashes compatibles con atributos antes de imponer. Comprobar con herramientas del navegador Report-Only, hidratación, navegación y 404; no prometer que el simple conteo de bloques demuestra compatibilidad. Para minimizar exposición del referente, se propone `Referrer-Policy: no-referrer` en lugar de la alternativa `strict-origin-when-cross-origin` de la tabla, pendiente de decisión del propietario. HSTS sigue diferida hasta verificar HTTPS y redirección; `noindex` no reemplaza protección de acceso.

## Validación pendiente en el host

Comprobar HTTP y HTTPS, certificado, redirección, `curl -I` para portada, cada ruta, URL inexistente, JS y CSS, código 404 auténtico, MIME, cabeceras finales, consola y red del navegador, enlaces salientes, móvil e hidratación. Repetir tras una nueva compilación para detectar hashes CSP obsoletos y mezclas de versiones por caché. Ninguna cabecera se ha aplicado remotamente.
