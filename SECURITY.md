# Seguridad

Este prototipo procesa dos archivos CSV locales y genera derivados locales. No presta un servicio público. `publicationAllowed=false` y `.gitignore` no sustituyen permisos de archivos, aislamiento de directorios ni revisión humana de datos y derechos.

## Reporte de vulnerabilidades

Aún no se ha designado ni verificado un contacto privado de seguridad o una política de respuesta. No incluyas detalles explotables, credenciales ni datos presupuestarios sensibles en incidencias públicas. Hasta que se habilite un canal privado confirmado por el propietario, solicita un canal de comunicación adecuado sin revelar el problema en público. No se promete plazo de respuesta ni se afirma que GitHub private vulnerability reporting esté habilitado.

## Alcance de las pruebas

Usa sólo fixtures sintéticos y copias autorizadas. No intentes eludir permisos del sistema, atacar servicios externos, subir archivos oficiales ni publicar importes. Los límites conocidos y resultados de seguridad están en `MISSION-003-FINAL.md` y `MISSION-003-VALIDATION.md`.
